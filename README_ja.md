# csTimer Solve Recorder

[English](README.md) | **日本語**

[csTimer](https://cstimer.net/) の計測に合わせて Web カメラで録画し、**速かった回・ベストを更新した回・残したい回だけ**を自動で保存する Chrome 拡張機能です。

## 主な機能

- **自動で録画**：スペースを押すと録画を開始し、タイマーが止まると録画を終了します。
- **さかのぼって録画**：スペースを押す 3〜4 秒前からの映像も残ります。秒数は設定で変えられます。
- **保存する条件**：次のどれか 1 つを満たした回を保存します。
  - セッションベストを更新した（ファイル名の末尾に `_BEST`）
  - 設定した秒数以下だった
  - 強制保存した（ファイル名の末尾に `_force`）
- **強制保存**：画面のボタン、または `Option`（`Alt`）+ `S` で使えます。
  - 録画中に押すと、その回を保存するよう予約します。
  - 解き終わってから押すと、保存されなかった直前の動画を保存します（初期設定では 60 秒以内）。
- **保存先**：ダウンロードフォルダの中の指定したフォルダに保存します（初期設定は `cstimer_rec`）。
- **プレビュー**：画面右上に表示します。表示・非表示と幅をポップアップで変えられます。
- タイムには `+2` が反映され、DNF もわかるようにファイル名に入ります。

ファイル名の例：`cstimer_2026-11-01_155243_12.34s_#1122_BEST.mp4`

## 動作環境

- Google Chrome 111 以降（デスクトップ版）
- Web カメラ
- 動作を確認した環境：macOS + Chrome

## インストール

1. このリポジトリをダウンロードし、展開します。
2. Chrome で `chrome://extensions` を開きます。
3. 右上の「**デベロッパーモード**」をオンにします。
4. 「**パッケージ化されていない拡張機能を読み込む**」を押し、`manifest.json` が入っているフォルダを選びます。
5. csTimer を開くか再読み込みし、カメラの使用を許可します。
6. プレビューの左上に「待機中 v0.5.0」と表示されれば準備完了です。

> Chrome の設定で「**ダウンロード前に各ファイルの保存場所を確認する**」がオンになっていると、保存のたびにダイアログが出ます。オフにしてください。

## 使い方

1. いつもどおり csTimer で計測します。
2. 保存する条件を満たすと、動画が自動で保存されます。
3. 条件を満たしていなくても残したい回は、強制保存を使います。
4. 録画を取りやめたいときは、録画中に `Esc` を押します。

## 設定

拡張機能のアイコンをクリックすると設定画面が開きます。

| 項目 | 初期値 | 説明 |
|---|---|---|
| プレビューを表示 | オン | 右上のカメラ映像を表示する（表示しなくても録画はされる） |
| 幅 | 240px | プレビューの幅（80〜800px、すぐ反映される） |
| セッションベスト更新 | オン | 現在のセッションで最速なら保存する |
| しきい値以下 | オン | 設定した秒数以下なら保存する |
| しきい値 | 30 秒 | 保存する基準の秒数 |
| 保存先 | `cstimer_rec` | ダウンロードフォルダからのパス（例：`cube/3x3`）。空欄ならダウンロードフォルダの直下 |
| 開始前にさかのぼる秒数 | 3 秒 | 0 にするとさかのぼらない |
| 停止後に録る秒数 | 1.5 秒 | タイマー停止後に続けて録画する長さ |
| 未保存の動画を残す秒数 | 60 秒 | この時間内なら強制保存で後から保存できる |

## 仕組み

- タイマーが止まったかどうかは、csTimer の記録が 1 件増えたかで判断します。記録は読み取るだけで、書き込み・変更・削除はしません。
- さかのぼり録画のため、待機中も 1 秒ごとに短い録画を回しています。そのぶん、待機中も CPU を少し使います。
- 動画はブラウザの中だけで処理し、外部には送信しません。

## 制限事項

- 録画を始めるきっかけはスペースキーだけです。タッチ操作や Stackmat での開始には対応していません。
- フライングした場合、その録画は次の 1 回分と一緒になります。
- csTimer で記録を保存する前に確認する設定にしていると、確認するまで動画の保存が遅れます。
- 残しておける未保存の動画は、直前の 1 本だけです。
- csTimer の内部仕様が変わると、正しく動かなくなることがあります。
- 動画の形式は MP4 です。MP4 に対応していない環境では WebM になります。
